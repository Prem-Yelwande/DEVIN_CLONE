# Project Documentation

Welcome to the Landing Page project. This is a lightweight, responsive landing page template built with HTML, CSS, and JavaScript.

## How to Open the Project

1.  **Clone or Download:** Ensure you have all the project files in a single directory.
2.  **Open in Browser:** Simply open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3.  **Development:** If you are making changes, you can use a local development server (like Live Server in VS Code) to see changes in real-time.

## Project Structure

- `index.html`: The main structure of the landing page.
- `css/styles.css`: Contains all styling, including CSS variables for easy customization.
- `js/main.js`: Handles interactivity (e.g., mobile menu toggle).
- `assets/`: Directory for documentation and potential assets.

## Dependencies

This project utilizes the following external resources:

- **Google Fonts:** Used for typography. Specifically, the 'Inter' font family is imported via Google Fonts API.
- **FontAwesome:** Included via CDN for scalable vector icons.

## Theme Customization

The project uses CSS variables defined in the `:root` selector within `css/styles.css`. You can easily customize the look and feel of the site by modifying these values:

```css
:root {
    --color-primary: #2563eb; /* Change primary brand color */
    --color-text-main: #1f2937; /* Change main text color */
    --color-bg-body: #f9fafb; /* Change background color */
    --font-family: 'Inter', sans-serif; /* Change font family */
    /* ... other variables */
}
```
